# Family Road Trip 2026

2026-09-25 至 2026-10-03，一家四大一小自驾旅行路书。

路线：宁波 → 日照 → 威海/荣成 → 烟台 → 北京 → 临沂 → 杭州临平

## 功能
- 手机优先单页路书
- 每日时间轴
- 高德一键导航
- 酒店信息本地保存
- 天气预报（Open-Meteo）
- 每日完成打卡与总进度
- 准备清单
- 大字体模式
- 北京官方预约入口
